BLOQUE 1 — /drive (Google Drive search)
---------------------------------------------------------

OBJETIVO: Que el comando /drive <búsqueda> funcione en Telegram.

PASO 1: Obtener el ID de tu carpeta de Google Drive
  - Abre Google Drive en el navegador
  - Navega a la carpeta que contiene tu biblioteca de contenido (posts, reels, propuestas, etc.)
  - Copia el ID de la URL: https://drive.google.com/drive/folders/[ESTE_ES_EL_ID]
  - Guarda ese ID, lo necesitas en el paso 3

PASO 2: Crear credencial Google Drive en n8n
  - Abre n8n: http://localhost:5678
  - Ve a Settings → Credentials → New Credential
  - Busca "Google OAuth2 API" (la genérica, no la específica de Calendar o Sheets)
  - Configura los scopes: https://www.googleapis.com/auth/drive.readonly
  - Completa el flujo OAuth con tu cuenta de Google
  - Guarda la credencial y anota su nombre/ID (lo necesitas en el paso 4)

  ALTERNATIVA más rápida: Si las credenciales de Sheets o Calendar ya tienen
  scope de Drive, puedes usarlas directamente en el nodo Google Drive de n8n
  sin crear credenciales nuevas. Verifica los scopes en la credencial existente.

PASO 3: Actualizar .env con el folder ID
  - Abre /home/anuarbarrera/miagent/chatbot/.env
  - Cambia la línea: GOOGLE_DRIVE_FOLDER_ID=
  - Por: GOOGLE_DRIVE_FOLDER_ID=<el ID del paso 1>
  - Reinicia rqworker: docker compose up -d rqworker

PASO 4: Crear workflow "drive_search" en n8n
  Crear nuevo workflow con nombre exacto: drive_search
  El workflow tiene 5 nodos en este orden:

  NODO 1 — Webhook (trigger)
    Tipo: Webhook
    Method: POST
    Path: drive_search
    Response Mode: Using 'Respond to Webhook' Node

  NODO 2 — Google Drive (buscar archivos)
    Tipo: Google Drive
    Operation: Search Files
    Query String:
      ={{ $('Webhook').first().json.body.params.query }} and '{{ $('Webhook').first().json.body.params.folder_id }}' in parents
    Credential: la que creaste en el Paso 2
    Options → Fields: files(id,name,mimeType,webViewLink,modifiedTime)

  NODO 3 — Code (formatear resultados)
    Tipo: Code
    JavaScript:
      const wb = $('Webhook').first().json.body;
      const items = $input.all();
      const files = items.map(item => ({
        name: item.json.name,
        url: item.json.webViewLink,
        type: item.json.mimeType,
        modified: item.json.modifiedTime
      }));
      return [{ json: {
        job_id: wb.job_id,
        chat_id: wb.chat_id,
        query: wb.params.query,
        total: files.length,
        files: files
      }}];

  NODO 4 — HTTP Request (callback a Django)
    Tipo: HTTP Request
    Method: POST
    URL: http://172.17.0.1:3001/api/v1/agent/n8n/callback/
    Headers:
      X-N8N-Token: <valor de N8N_CALLBACK_TOKEN en tu .env>
      Content-Type: application/json
    Body Type: JSON (usar "Specify Body" = Using Fields Below)
    Body Parameters:
      job_id  = {{ $json.job_id }}
      chat_id = {{ $json.chat_id }}
      status  = ok
      data    = {{ JSON.stringify({query: $json.query, total: $json.total, files: $json.files}) }}

  NODO 5 — Respond to Webhook
    Tipo: Respond to Webhook
    Respond With: JSON
    Response Body: {"ok": true}

  Conectar nodos en orden: 1→2→3→4→3 (Code también conecta a 5)
  Activar el workflow con el toggle "Active"

  Resultado esperado: lista de archivos de Drive que contengan "propuesta" en el nombre

BLOQUE 2 — /prospecto con URL de Facebook (competitor)
---------------------------------------------------------

OBJETIVO: Que /prospecto "Empresa X" https://facebook.com/empresa funcione.

REQUISITO: Tienes un token de Facebook válido en n8n
  (el mismo que usan facebook_stats_tuwebmx y facebook_stats_anuarbarrera).

PASO 1: Crear workflow "facebook_competitor" en n8n
  Crear nuevo workflow con nombre exacto: facebook_competitor

  NODO 1 — Webhook
    Method: POST
    Path: facebook_competitor
    Response Mode: Using 'Respond to Webhook' Node

  NODO 2 — Code (extraer page ID de la URL)
    Tipo: Code
    JavaScript:
      const wb = $input.first().json.body;
      const url = wb.params.url;
      const parts = url.replace(/\?.*$/, '').split('/').filter(
        p => p && !['www.facebook.com','facebook.com','https:',''].includes(p)
      );
      const pageId = parts[parts.length - 1] || parts[0];
      return [{ json: {
        job_id: wb.job_id,
        chat_id: wb.chat_id,
        name: wb.params.name,
        page_id: pageId,
        original_url: url
      }}];

  NODO 3 — HTTP Request (Facebook Graph API)
    Tipo: HTTP Request
    Method: GET
    URL: https://graph.facebook.com/v20.0/{{ $json.page_id }}
    Query Parameters:
      fields = name,fan_count,followers_count,category,about,posts{message,created_time,likes.summary(true),comments.summary(true),shares}
      access_token = <PEGA AQUÍ EL TOKEN DE FACEBOOK>

    CÓMO OBTENER EL TOKEN: Abre el workflow "facebook_stats_tuwebmx" en n8n,
    encuentra el nodo HTTP Request que llama a graph.facebook.com, copia el
    valor del parámetro access_token.

  NODO 4 — Code (formatear datos)
    Tipo: Code
    JavaScript:
      const wb = $('Extract Page ID').first().json;
      const page = $input.first().json;
      const posts = (page.posts && page.posts.data) ? page.posts.data.slice(0, 5) : [];
      const totalLikes = posts.reduce((sum, p) => sum + (p.likes && p.likes.summary ? p.likes.summary.total_count : 0), 0);
      const totalComments = posts.reduce((sum, p) => sum + (p.comments && p.comments.summary ? p.comments.summary.total_count : 0), 0);
      const avgEngagement = posts.length > 0 ? Math.round((totalLikes + totalComments) / posts.length) : 0;
      return [{ json: {
        job_id: wb.job_id,
        chat_id: wb.chat_id,
        platform: 'facebook',
        competitor_name: wb.name,
        page_name: page.name,
        fans: page.fan_count || 0,
        followers: page.followers_count || 0,
        category: page.category || '',
        about: (page.about || '').slice(0, 200),
        recent_posts: posts.length,
        avg_engagement: avgEngagement,
        url: wb.original_url
      }}];

    IMPORTANTE: Renombrar el nodo 2 a "Extract Page ID" para que el Code
    del nodo 4 pueda referenciarlo con $('Extract Page ID').

  NODO 5 — HTTP Request (callback Django)
    Igual que en drive_search NODO 4, pero con estos body params:
      job_id  = {{ $json.job_id }}
      chat_id = {{ $json.chat_id }}
      status  = ok
      data    = {{ JSON.stringify({platform: $json.platform, competitor_name: $json.competitor_name, page_name: $json.page_name, fans: $json.fans, followers: $json.followers, category: $json.category, about: $json.about, recent_posts: $json.recent_posts, avg_engagement: $json.avg_engagement, url: $json.url}) }}

  NODO 6 — Respond to Webhook

  Activar el workflow.
